旧 S1 把完整固定材料直接放入上下文，48 个适用单元的实际输入约为 416 万 tokens，远高于 24,576 的输入上限。材料、题目和 tokenizer 均不变时，重复这一构造仍然超限，不能增加回答质量证据。本轮保留其已验证的超限观察和完整材料身份。

## 比较与收工记录

比较方案应在生成前固定。建议分别登记旧 S2 与新 S2、旧 S3 与新 S3、旧 S5 与新 S5，以及新 S2 与新 S3、新 S3 与新 S5 的成对问题集合。引用旧 S0 的对照必须标明跨轮比较。不同对照有各自的适用范围和分母，不能合并成一个共同成功率。

每组成对比较先报告全部适用题、两侧状态及失败数；答案质量分析再列出可评分的配对数、排除题号和原因。已生成且可评分的拒答必须保留，不能为了提高结果而删除。工程状态、检索证据覆盖和后续科学评分分别报告。跨轮耗时差异需标明运行环境与时间，不能仅凭历史与新轮耗时直接归因于检索算法。

这属于对[原设计共同分母](rag_value_ablation_design.md)的显式分析方案修订：按对照分别建立配对集合，可以保留有信息的局部比较，但不能据此声称六个生成条件已有共同、完整的质量比较。涉及人工标签的指标仍须等待真实专家评分，不能从 `completed`、非空检索或自动校验通过推导。

本轮按执行范围收工，需要 159 个新状态单元完整且通过独立机器审计，实际生成回执和原始答案可追溯，超限、超时及校验失败如实保留，并完成 212 个历史引用的身份核验。报告必须分别统计本轮新执行、本轮确认生成、历史引用和未评分内容。只完成这些工程步骤，不表示专家评分或完整七条件科研结论已经完成。
